# BEWAY — вебплатформа

**Слоган:** Знайди свій шлях через досвід
**Статус:** підготовка першого пілоту. Усі професійні напрями на сайті демонстраційні.

## Стек

| Частина | Технологія | Чому так |
|---|---|---|
| Фронтенд | Astro 5, статична збірка | Публічні сторінки живуть з органічного пошуку: потрібен SSG і мінімум JS. Інтерактив лише там, де він справді потрібен (фільтри каталогу) |
| Стилі | один `global.css` із токенами | Дизайн-система в одному місці, без залежностей і без рантайм-CSS |
| Бекенд | ASP.NET Core 8, Minimal API | Поки каркас. Коли зʼявляться заявки, автентифікація й права доступу — це пишеться на C# з EF Core |
| БД | немає | Створюється після моделі даних і правових підстав, не раніше |

Фронтенд і API деплояться окремо. Фронтенд — будь-який статичний хостинг,
API — окремий сервіс. Зараз фронтенд від API не залежить.

## Запуск

Потрібні Node.js 20+ і (для API) .NET SDK 8.

```bash
cd frontend
npm install
npm run dev          # http://localhost:4321
npm run build        # статика в frontend/dist/
npm run preview
```

```bash
cd backend/BEWAY.Api
dotnet run           # /api/health, /api/status
```

## Налаштування

```bash
cp frontend/.env.example frontend/.env
```

`PUBLIC_SITE_URL` впливає на canonical, Open Graph і sitemap.
**Перед продакшн-деплоєм замінити на реальний домен** — інакше в мапі сайту
й canonical буде чужа адреса.

Дозволені origin для API задаються в `appsettings.json` у секції `Cors:AllowedOrigins`.
Ключів доступу в репозиторії немає й не повинно бути.

## Структура

```
frontend/
  src/components/   Logo, Header, Footer, спрайт іконок
  src/layouts/      Base.astro — head, SEO, скелет сторінки
  src/pages/        маршрути, зокрема opportunities/[slug]
  src/data/         opportunities.ts — демодані каталогу
  src/styles/       global.css — уся дизайн-система
  public/assets/    beway-symbol.svg
backend/BEWAY.Api/  Minimal API
docs/               аудит бренду, статус функцій, матеріали для Youthquake
docs/brand/         оригінальний растровий референс логотипа (не їде в продакшн)
```

## Правила, які не можна порушувати

- Жодних вигаданих компаній, партнерів, наставників, відгуків чи кількостей користувачів
- Жодної кнопки, яка виглядає робочою, але нічого не робить
- Жодної форми, яка показує успіх, не зберігши дані
- Слово **«безкоштовно»**, ніколи «безплатно»
- Користувачі — це «молодь», «людина», «учасник», а не «студенти»
- Статистика досліджень завжди з розміром вибірки й застереженням про обмеження
- Без асоціацій із картами, навігаторами й маршрутами, попри WAY у назві

## Наступні кроки

1. ER-діаграма, матриця прав доступу й схема руху даних для модуля 6 Youthquake
2. Майстер-файл логотипа від дизайнера (поточний SVG — реконструкція, біла хвиля на третину тонша за оригінал)
3. Ліцензовані фотографії професій за ТЗ §9
4. Локальне розміщення шрифтів замість Google Fonts
5. Правове проєктування збору даних перед увімкненням будь-яких форм
6. Lighthouse і ручна перевірка скрінрідером на реальному пристрої
