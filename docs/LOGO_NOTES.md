# Векторний знак BEWAY
Вхідний файл: `лого BEWAY.png` із розмови користувача. Це оригінал, наданий користувачем.

Створено SVG вручну через криві Безьє, з трьома незалежними формами (синій верх, бірюзовий низ, біла розділювальна хвиля). Для перевірки точності слід накласти SVG на PNG і за потреби коригувати вузли у Figma, Illustrator або Inkscape.

Повний логотип `beway-logo.svg` містить окремий текстовий елемент `BEWAY`, який легко редагувати. Відкривайте його як SVG, а не як вбудовану растрову картинку. Через різницю встановлених шрифтів інтервали можуть трохи змінитися.
