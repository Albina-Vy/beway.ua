# BEWAY | Інформація для Claude

## Статус
Нова стартова версія, а не відновлений оригінал PROживи. Попередній публічний демосайт: https://prozhyvy.netlify.app/

## Позиціонування
BEWAY (БІВЕЙ). Слоган: «Знайди свій шлях через досвід». Кар'єрна платформа для молоді 18–35 років, не лише студентів. Компанії, наставники, освітні партнери. Професійні проби на старті плануються безкоштовними; без гарантій працевлаштування.

## Путь учасника
Каталог → підтверджена картка проби → заявка → погодження компанією → проба з наставником → двосторонній відгук → Career Route.

## Термінологія
Уникай довгого тире у всіх публічних текстах. Не став крапку наприкінці короткого слогану. Використовуй слово «безкоштовно». Не зводь платформу до IT або студентів. Не створюй навігаційні або картографічні метафори.

## Айдентика
Space Grotesk + Manrope. Dark #14263D, Blue #2D6BFF, Aqua #34D5C8, Light #F4F8FC. Прозорий SVG логотипа в assets. Він є редагованою реконструкцією оригінального PNG, не векторним master-файлом від дизайнера.

## Дані та чесність
Модулі 1–4 Youthquake досліджували PROживи. 32 анкети, 5 інтерв'ю; 20/30 респондентів обрали цінність реального досвіду; 11 фідбеків по MVP, середня зручність 4,45/5; 13/16 зацікавленості CTA B проти 10/15 A. Це не доказ реальних проб або партнерів.

## Архітектура розширення
Пропозиція: Astro frontend, ASP.NET Core API, PostgreSQL тільки після обґрунтування вимог. Майбутні сутності Users, Organizations, Opportunities, Applications, Sessions, Feedback, CareerRoutes, Consents, AuditLogs. Мінімальні права доступу; окрема згода на маркетинг.

## Поточна реалізація
Адаптивна головна, каталог демонапрямів, сторінка напряму, how-it-works, partners, about, join, privacy. Пошук та фільтрація в каталозі працюють на клієнті. Діючої форми збору контактів немає з міркувань безпеки. Backend лише health/status endpoints.
