# Айдентика: виміряні проблеми й ухвалені рішення

Усе нижче перевірено на файлах, а не на око. Цифри відтворювані.

## 1. Space Grotesk не має кирилиці

Витяг із самого шрифтового файлу (`@fontsource/space-grotesk`):

```
субсети: latin, latin-ext, vietnamese
у таблиці символів відсутні: А Б Є І Ї Ґ є і ї ґ и й ь
```

Отже вимога ТЗ §8 «Space Grotesk Bold для великих заголовків» для українського тексту
нездійсненна: браузер посимвольно падає на наступний шрифт у стеку. Заголовки й так
рендерилися Manrope — просто неявно, і при цьому вантажилися три зайві ваги Space Grotesk.

**Рішення.** Space Grotesk лишається, але тільки для латиниці: напис BEWAY і номери
секцій. Українські заголовки — Manrope 800.

Manrope перевірено тим самим способом: кирилична підмножина має 105 символів,
українські Ґ, ґ, Є, І, Ї присутні. Апостроф U+2019 лежить у латинській підмножині,
тому обидві підмножини мають завантажуватися — для української це обовʼязково.

**Якщо потрібні дві різні гарнітури**, перевірені кандидати з повною українською
кирилицею: Unbounded (найближчий за характером до Space Grotesk), Onest, Sofia Sans.

## 2. Палітра не проходила WCAG 2.2 AA

Виміряна контрастність (поріг для основного тексту — 4.5:1):

| пара | ratio | AA текст |
|---|---|---|
| `#7B8794` на білому | 3.66 | ні |
| `#2D6BFF` на `#F4F8FC` | 4.22 | ні |
| `#34D5C8` на білому | 1.83 | ні |
| `#2D6BFF` на `#14263D` | 3.39 | ні |
| `#2D6BFF` на білому | 4.51 | так, на межі |
| `#34D5C8` на `#14263D` | 8.37 | так |

Фірмові кольори не змінювалися. Додано похідні токени тільки для тексту:
`--muted:#5C6676`, `--aqua-ink:#1A736C`, `--blue-ink:#0052FB`.

## 3. Кольори логотипа не збігаються з брендбуком

Піксельний аналіз `docs/brand/beway-original-reference.png`:

```
синій у знаку:     #0052FB   (брендбук каже #2D6BFF)
бірюзовий у знаку: #08DDCC   (брендбук каже #34D5C8)
```

Це розбіжність, яку має вирішити власник бренду. Корисний збіг: `#0052FB` дає
5.83:1 на білому проти 4.51:1 у `#2D6BFF`, тобто синій із самого логотипа
проходить AA із запасом. Тому він узятий як `--blue-ink` для тексту й посилань,
а `#2D6BFF` лишився для заливок і кнопок.

## 4. Текст усередині SVG не рендериться потрібним шрифтом

`beway-logo.svg` містив `<text font-family="Space Grotesk">`. SVG, підключений
через `<img src>`, — ізольований документ: він не вантажить зовнішні вебшрифти.
Напис BEWAY завжди показувався системним Arial, а не фірмовою гарнітурою.

**Рішення.** Файл видалено. Логотип зібрано в компоненті `Logo.astro`:
знак — inline SVG, напис — звичайний HTML-текст, до якого застосовується
завантажений Space Grotesk. Це також прибрало окремий мережевий запит.

## 5. У viewBox логотипа було 31.7% порожнечі

`beway-logo.svg` мав `viewBox="0 0 1020 210"`, а реальні межі знака — `x 11–696`.
При `width:178px` видима ширина становила ≈120px, решта — невидимий відступ,
через що логотип виглядав меншим і зміщеним. `beway-symbol.svg` переведено
на щільний `viewBox="36 18 728 798"`.

## 6. Векторна реконструкція знака — точна, крім товщини хвилі

Порівняння SVG із оригінальним PNG після нормалізації за габаритами:

```
співвідношення сторін: оригінал 0.921, SVG 0.934  (відхилення +1.5%)
IoU силуетів: 98.6%
площа білої розділювальної хвилі: оригінал 10.74%, SVG 7.36%
```

Силует відтворено добре. Єдиний помітний дефект — **біла хвиля на третину тонша
за оригінал**. Це видно при великому розмірі знака. Виправляти вручну в коді
не варто: потрібен правильний майстер-файл від дизайнера або коригування вузлів
у Figma чи Inkscape.

Окремо: вихідний PNG має рвані краї й поодинокі артефакти по периметру —
це не чистий майстер-файл. Для друку й великих форматів він не придатний.
